## Descrição do Projeto

Este projeto é uma implementação do jogo **Space Invaders** usando a linguagem de programação **Haskell** e a biblioteca **Gloss** para a renderização gráfica. A implementação foi baseada em um tutorial disponível na página da disciplina sobre o jogo **Arkanoid**, que pode ser consultado em: [Tutorial Arkanoid](https://haskell.pesquisa.ufabc.edu.br/Haskell2018/files/arkanoid.pdf).

## Requisitos

Para rodar o projeto, você precisará instalar o **FreeGLUT**. Você pode fazer isso com o seguinte comando:

```bash
sudo apt-get install freeglut3-dev
```


## Como Utilizar

1. Clone o repositório do projeto

2. Navegue até o diretório do projeto

3. Compile e execute o projeto usando o Stack:
```bash
stack run
```

## Instruções de Controle
- **Setas Esquerda e Direita**: Movimentar o jogador.
- **Tecla "z"**: Atirar/Selecionar Opção do Menu.
